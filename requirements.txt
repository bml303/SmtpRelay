# Pinned dependency set for smtp-relay.
#
# Every version is exact, so a fresh install reproduces this environment.
# This file installs on Linux and Windows WITHOUT a C/C++ compiler: the only
# compiled packages are pydantic-core and pywin32, and both have complete wheels
# for win_amd64 and win_arm64 across cp311-cp315.
#
# That property depends on uvicorn being declared WITHOUT its [standard] extra.
# The extra pulls in httptools, PyYAML, watchfiles, websockets, python-dotenv and
# uvloop; PyYAML has no win_amd64 wheel for cp3.15 and no win_arm64 wheel for
# cp3.11, which silently turns `pip install` into a source build requiring
# Visual Studio Build Tools for C++. None of those six are used here.
# tests/test_windows_deployment.py guards against reintroducing them.
#
# Regenerate after changing pyproject.toml:
#   .venv/bin/python -m pip install -e '.[dev]'
#   .venv/bin/python -m pip freeze --exclude-editable > requirements.txt
#
# WARNING: `pip freeze` runs on the current platform only. Regenerating on Linux
# drops the Windows entry below, so after regenerating you must restore the
# "platform-specific" block at the bottom of this file.
#
# Note: this is a single flat file, so it includes the test-only packages
# (pytest, httpx, aiosmtpd). For a production install that skips them, use
# `pip install .` (add `.[windows]` when deploying as a Windows service).
#
# The project itself is intentionally absent (--exclude-editable); install it
# with `pip install .` or `pip install -e .` after these requirements.
