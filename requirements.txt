# Runtime dependency set for smtp-relay: exactly what the service imports,
# pinned to exact versions, for every target (win_amd64, win_arm64,
# linux_x86_64, linux_aarch64, the container image). This is what the payloads
# bundle and what the installers install. Test-only packages live in
# requirements-dev.txt, which includes this file.
#
# Installs WITHOUT a C/C++ compiler everywhere: the only compiled packages are
# pydantic-core, pywin32, cffi and cryptography, all with complete wheels for
# cp311-cp315 on every target (cryptography is held at the newest release that
# still publishes win_arm64 wheels; see the note at its pin). That
# property depends on uvicorn being declared WITHOUT its [standard] extra
# (httptools, PyYAML, watchfiles, websockets, python-dotenv, uvloop are neither
# used nor wheel-complete on Windows); tests/test_windows_deployment.py guards it.
#
# Regenerate after changing [project.dependencies] in pyproject.toml, from a
# clean venv so nothing from the dev set leaks in:
#   python3 -m venv /tmp/rt && /tmp/rt/bin/pip install . && /tmp/rt/bin/pip freeze --exclude smtp-relay
# then restore the platform-specific block at the bottom. scripts/build_dist.py
# verifies the closure for the target platform and refuses to build if a
# transitive dependency is missing.
